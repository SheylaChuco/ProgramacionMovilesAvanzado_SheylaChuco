# Semana 06 - Programación en Móviles Avanzado

Autora: Sheyla Chuco

## Semana06_02 - Datos del cliente (ventana modal)

**Requerimientos funcionales**

- RF-01: El sistema debe permitir registrar los datos de un cliente (apellidos, nombres y DNI).
- RF-02: El sistema debe almacenar los datos registrados en una entidad `ClienteModel`.
- RF-03: El sistema debe mostrar los datos del cliente en una ventana modal independiente.
- RF-04: El sistema debe permitir cerrar la ventana modal y regresar al formulario.

## Semana06_03 - Calculadora de venta a plazos

**Requerimientos funcionales**

- RF-01: El sistema debe permitir registrar una venta (electrodoméstico, precio unitario, cantidad, meses y tasa de interés mensual).
- RF-02: El sistema debe calcular el subtotal, el IGV (18%), el monto base, los intereses totales, el total a pagar y la cuota mensual.
- RF-03: El sistema debe almacenar los resultados en una entidad `VentaModel` y enviarlos a la pantalla de resultado.
- RF-04: El sistema debe mostrar los resultados en soles con dos decimales.

**Prueba:** precio 1000, cantidad 2, 6 meses, tasa 2% → total S/. 2643.20 y cuota S/. 440.53.
